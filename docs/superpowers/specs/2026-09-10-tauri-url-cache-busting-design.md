# Tauri 站点 URL 缓存失效设计

## 目标

Tauri 应用每次启动或创建窗口时，为实际加载的站点 URL 添加新的毫秒级时间戳查询参数，避免站点发版后 WebView 继续使用旧入口页面缓存。

## 方案

- 保持 `.env.test`、`.env.uat`、`.env.prod` 中的 `TAURI_ENV_URL` 为稳定的基础地址。
- 在 `/Volumes/TRANSCEND/works/objects/github/backstage68/src-tauri/src/lib.rs` 中集中实现 URL 缓存失效函数。
- 每次主窗口、macOS 重开窗口或命令创建新窗口时，生成当前 Unix 毫秒时间戳，并将其写入 `_t` 查询参数。
- 如果 URL 已含 `_t`，替换旧值而不是追加重复参数。
- 保留其他查询参数、路径和片段标识符。
- 创建新窗口时，无论使用环境基础 URL 还是传入的当前页面 URL，都刷新 `_t`。

## 错误处理

- 使用现有 URL 解析能力处理查询参数，避免手工拼接造成 `?`、`&` 或 `#` 位置错误。
- URL 无法解析或系统时间早于 Unix 纪元时，返回明确错误；主窗口启动沿用当前的致命启动错误处理，新窗口命令向调用方返回错误。

## 验证

- 单元测试覆盖：无查询参数、已有其他查询参数、已有 `_t`、带片段标识符。
- 运行 Rust 格式化、相关测试和编译检查。

## 范围

只改变窗口首次加载的 URL。页面在同一窗口内刷新或跳转时不会主动生成新时间戳。
